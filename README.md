# 아이언 스트라이커

`output/imagegen/` 에 준비된 기체·적기·보스·배경 이미지와 컨셉 문서를 바탕으로 만든
7스테이지 종스크롤 비행 슈팅 게임입니다. 고전 아케이드 프로펠러 슈팅의 구성(잔기·폭탄·
파워업·차지 공격·지상 목표물·다단계 보스)을 참고했고, 화면 구성과 적 패턴·수치는 이
프로젝트에 맞춰 새로 만들었습니다.

에셋 제작 규격과 남은 작업은 [HANDOVER.md](HANDOVER.md)에 있습니다.

새 4탄 밀림 협곡과 5탄 화산 기지에는 내장 ImageGen으로 만든 기체·중간보스·보스 6장과
배경 2장을 사용합니다. [일곱 전선 원화 미리보기](tools/seven-stage-art.html)에서 볼 수 있습니다.
사용 파일은 `assets/{canopy,caldera}-*-v1.*`, 생성 프롬프트와 원본 위치는
[ImageGen 기록](assets/seven-stage-imagegen-v1.json)에 보관했습니다. 원본 사본은
`../output/imagegen/seven-stage-v1/`에 있습니다. 신규 기체를 그리는 HTML/CSS 도형은 사용하지 않습니다.

기존 4·5탄은 각각 6·7탄으로 이동했습니다. 기존 배경 식별자 `bg4`·`bg5`와 원화 파일명은 유지합니다.
밀림 중무장기 `assets/canopy-gunship-v1.png`와 화산 폭격기 `assets/caldera-bomber-v1.png`도
내장 ImageGen으로 추가 제작했습니다. 프롬프트와 원본 경로는 [추가 원화 기록](assets/phase-variety-imagegen-v1.json)에 있습니다.
요격기와 무장 역할의 외형을 구분하며, 기존 역할의 체력·탄속·피격 반지름을 사용합니다.
6탄 원화 13장과 좌·정면·우 자세는 [야간 원화 미리보기](tools/stage4-art.html)에서
비교할 수 있습니다. 파일명 변경 내역은 [대조표](assets/stage4-rename-map.json)에 기록했습니다.
경비정·미사일정·중포탑·쌍로터 공격기·해상 요새를 6탄에 적용했고, 쌍로터 내부 팬은
원화에서 추출한 8프레임을 순환합니다. 이 원화들은 야간 배경과 함께 필요한 시점에 로드됩니다.

나이트 아크의 아래쪽 게이지는 **부위별 내구도**, 위쪽 긴 게이지는 **선체 체력**입니다.
좌·우 무장부를 겨냥하면 해당 내구도가 줄고, 0이 되면 그 자리에서 폭발한 뒤 잔해로 바뀝니다.
잔해가 된 자리는 조용해지지 않고, 조준을 잃은 대신 더 넓은 탄막을 같은 주기로 뿜습니다.
함교는 2단계부터 장갑이 열리고, 파괴하면 조준을 잃는 대신 전방을 덮는 탄벽으로 바뀝니다.
부위를 모두 파괴해도 중앙 주포와 선체가 남으므로 선체 체력을 소진해야 격파됩니다.
[부위 파괴·폭발 미리보기](tools/boss-effects-preview.html)에서 각 파괴 상태를 비교할 수 있습니다.
폭발은 `assets/explosion.png`(16프레임 원화 `explosion-sheet-v1.png`의 축소본)를 재생합니다.

## 화면 구성

메뉴·한글 안내·숫자·캔버스 HUD는 한글 아케이드 서체 **Neo둥근모**를 씁니다.
`assets/fonts/neodgm.woff2`를 함께 배포하므로 실행 시 외부 폰트 서버에 접속하지 않습니다.
공식 출처는 https://github.com/neodgm/neodgm-webfont 이며 SIL OFL 1.1 전문은
`assets/fonts/OFL.txt`에 포함했습니다. 캔버스를 처음 그리기 전에 폰트 로딩을 기다립니다.

타이틀은 아케이드풍 영문 화면(IRON STRIKER)입니다. 로고는 `assets/title-logo.png`의 금속 이미지이며, 입체 로고,
점수판, 기체 선택 카드
(실제 스프라이트 + 한국어 성능 막대 화력·확산·차지), PRESS START, 아이콘 옵션 칩,
왕관 표시가 있는 최고 기록표로 구성됩니다. 게임 중 HUD와 조작 안내 본문은 한국어입니다.

뒤에서는 **대기화면 데모(어트랙트 모드)** 가 돌아갑니다. 12초마다 스테이지가 바뀌면서 그
배경·적 구성·지상 시설이 나오고, 후반에는 그 스테이지 보스가 등장합니다. 13초 동안 조작이
없으면 안내 패널이 사라지고 데모만 남아 스테이지 이름과 PRESS START가 표시되며,
아무 키나 화면을 누르면 패널이 다시 나타납니다. 이때 다음 스테이지 배경을 미리 받아 두므로
실제 플레이에서 스테이지 전환이 끊기지 않습니다.

## 실행

`index.html` 을 브라우저에서 엽니다. 로컬 파일(`file://`)로 열어도 동작하지만, 브라우저에
따라 로컬 이미지 접근이 제한될 수 있으므로 문제가 있으면 로컬 서버로 여는 편이 확실합니다.

```sh
cd striker-game
python -m http.server 8000   # http://localhost:8000
```

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Z 또는 Space | 발사(누르고 있으면 차지 게이지가 참) |
| X | 필살기 — 지원기 등장, 전장에 미사일 25발 투하, 착탄 시 피해 |
| Shift | 저속 이동 |
| P / Esc | 일시정지 |
| 드래그 | 마우스·터치 이동(터치는 자동 발사) |
| 화면 버튼 | 터치 기기에서 `차지`, `폭탄`, 우측 상단 `Ⅱ` 일시정지 |

일시정지 화면의 `계속하기`를 누르면 3→2→1을 표시한 뒤 재개합니다. 준비 중에는 기체·탄막·보스
격파·점수·배경음이 멈추며, 이전에 누르고 있던 이동·차지·폭탄 입력은 비웁니다.
카운트다운 중 `P`/`Esc` 또는 화면 `Ⅱ`를 누르거나 탭을 숨기면 다시 일시정지합니다.

차지 게이지가 가득 차면 관통 차지샷이 나갑니다. 기본값은 자동 발사(터치 자동 연사에서도
쓸 수 있도록)이며, 타이틀에서 끄면 발사 버튼을 뗄 때만 나갑니다.

필살기는 `bomb_planet.png` 지원기를 폭 520px로 표시하고, 아래에서 위로 0.72초 만에 통과시킵니다.
그 앞쪽 레이어에서 `bomb_missile.png` 25발이 화면 아래에서 수직 가속으로 솟아오릅니다.
기체와 같은 방향이라 맨 아랫줄이 먼저 터지고 위로 훑어 올라갑니다.
기수가 착탄점에 닿으면 같은 위치에 필살기 전용 `assets/bomb-impact-sheet-v1.png`의
탑뷰 폭발 16프레임을 재생합니다. 섬광 → 방사형 화염 → 잔불·연기 순서이며 전체 연출은 2.2초입니다.
원화는 ImageGen 내장 도구로 제작했고 [제작 프롬프트](assets/bomb-impact-prompt.md)를 함께 보관합니다.
발동 즉시 적탄을 지우고 연출 전체에 무적을 적용합니다. 피해는 착탄 시 발생하며,
한 번의 필살기에서 같은 대상은 한 번만 피해를 받습니다(적 140, 지상 120, 보스 350).
연출 중 중복 발동은 막고, 일시정지·스테이지 전환에 맞춰 연출도 정지·정리됩니다.
[필살기 미리보기](tools/bomb-preview.html)에서 재생·일시정지·시간 이동으로 확인할 수 있습니다.

## 기체

### 적 특수 편대

원화의 명암과 좌·정면·우 자세를 보존한 색조 도장을 적용합니다. 회전 프로펠러도 유지하며,
검은 기체는 밝은 금속 명암과 별도 꼬리 표식으로 야간 배경에서도 구분합니다.

| 기종 | 도장 | 움직임 | 공격 |
|---|---|---|---|
| 레드 팽 | 진홍색 | 진입 후 반대편으로 교차 급강하 | 양 날개 2발 사격 |
| 스칼렛 에이스 | 주홍색 | 좌우로 기울이며 회피 비행 | 양 날개 2발 사격 |
| 블랙 레이븐 | 청흑색 | 상공 좌우 선회 후 이탈 | 조준 예고 후 고정 방향 3연사 |
| 옵시디언 | 흑철색 | 중장갑 저속 선회 후 이탈 | 중앙에 통로를 남기는 6발 탄막 |

1탄에는 빨간 편대, 2~3탄에는 검은 조준기, 4~5탄에는 중장갑 편대가 합류합니다.
기존 웨이브 일부를 교체하고 편대 수를 줄여 새 적이 한꺼번에 과도하게 늘지 않도록 했습니다.
[도장·자세·공격 미리보기](tools/enemy-variants.html)에서 기체와 낮/밤 배경을 선택할 수 있습니다.
`node tools/test-enemy-patterns.cjs`로 이동 이탈, 좌우 자세, 사격 방향·발수, 스테이지 배치를 검증합니다.

## 규칙

기본 지상 목표물 6종(대공포·전차·벙커·레이더·연료고·경비정)은 내장 ImageGen으로 제작한
투명 원화 9장을 사용합니다. 포신·포탑·안테나는 별도 이미지로 회전하며, 기존 공격과 피격 판정은 유지합니다.
원화는 `assets/ground/*-imagegen-v1.png`, 전체 프롬프트와 원본 위치는
[제작 기록](assets/ground/imagegen-v1.json), 고해상도 원본 사본은 `../output/imagegen/ground-v1/`에 있습니다.
[지상 원화 미리보기](tools/ground-art.html)에서 전장 배경과 조준점을 바꿔 볼 수 있습니다.
게임과 미리보기는 알파를 보존한 같은 이름의 `.webp` 사본을 로딩합니다.

- 피격 판정은 기체 중앙의 작은 원(반지름 3px)이며 날개·보조 포드는 스쳐도 안전합니다. EASY/HARD에 동일하게 적용됩니다.
- `P` 아이템으로 화력이 1~5단계까지 오릅니다. 격추 시 EASY는 한 단계 감소하고 HARD는 1단계로 돌아갑니다.
- 편대를 전멸시키면 아이템이 나옵니다. 연속 격추가 이어지면 점수 배율이 최대 ×5까지 오릅니다.
- 지상의 포탑·전차·벙커·레이더·연료고·경비정도 공격 대상입니다. 연료 저장고는 주변 시설까지
  함께 터집니다.
- 보스를 잡는 순간 화면에 남은 적탄이 점수로 바뀝니다.
- 중간보스를 격파해야 보스가 등장합니다. 보스 예정 시간이 지나도 중간보스가 살아 있으면 기다리고,
  격파 후 2.4초 경고를 거쳐 등장합니다. 일찍 격파하면 원래 예정 시간까지 기다립니다.
- 30만 점마다 잔기가 1 늘어납니다.
- 컨티뉴를 쓰면 그 판은 최고 점수와 기록표에 남지 않습니다.

### EASY / HARD

시작 화면에서 난이도를 선택합니다. 처음 접속할 때는 EASY이며 마지막 선택은 브라우저에 저장됩니다.
플레이 중에는 선택한 난이도가 유지됩니다. HUD·일시정지·엔딩에 현재 모드를 표시합니다.

| 항목 | EASY | HARD |
|---|---|---|
| 시작 잔기 / 폭탄 / 화력 | 5 / 3 / 2 | 3 / 2 / 1 |
| 편대 적 수 | 기본 수, HARD의 약 2/3 | 기존 1.5배 편대 |
| 일반 적 / 지상 목표 / 중간보스 체력 | HARD의 70% / 75% / 75% | 기존 설정 |
| 보스 선체 / 부위 내구도 | HARD의 80% | 기존 설정 |
| 적탄 속도 / 공격 타이머 진행 속도 | HARD의 78% / 80% | 기존 설정 |
| 큰 부채꼴·원형 탄막 | 탄 수 축소, 부채꼴 좌우 대칭 유지 | 기존 설정 |
| 격추 후 화력 / 부활 무적 | 한 단계 감소 / 4초 | 1로 초기화 / 2.8초 |

EASY·HARD의 최고 점수와 순위는 별도로 저장합니다. 기존 `is_hi`·`is_last`·`is_scores` 기록은
HARD에서 그대로 사용하며 EASY는 `is_easy_*`에 저장합니다. 잔기는 현재 기체 외의 여분 기체 수입니다.
속도 배율은 고정 속도 폭탄과 유도탄의 가속·최대 속도에도 적용됩니다.
설정은 `js/difficulty.js`, 수치 점검은 [난이도 점검 기록](tools/difficulty-review.md)에 있습니다.

2탄 듄 콜로서스의 주포는 한 번 조준한 각도로 두 포신이 번갈아 4·6·8발(단계별)을 연속으로
쏟아냅니다. 조준은 포격 시작 때 고정되므로 옆으로 비키면 탄막 전체를 피할 수 있습니다.

보스는 체력 66% / 33%를 기준으로 3단계로 패턴이 바뀌고, 2단계부터 숨어 있던 약점(함교·
반응로)이 드러납니다. 약점은 피해가 1.5배 들어가고 파괴하면 5,000점이 들어오지만,
남은 기체가 **폭주**합니다. 부서진 자리에서 조준 없는 탄막이 계속 뿜어지고, 파괴 비율만큼
연사 주기가 짧아지며 탄이 늘어납니다. 듄 콜로서스는 왕복 속도까지 빨라집니다.
1~7탄 모든 보스의 1·2·3단계에 적용되므로, 부위 파괴는 점수를 노린 선택이지 쉬운 길이 아닙니다.
HUD 오른쪽 위에 `폭주 n/m` 으로 몇 곳이 부서졌는지 표시됩니다.
보스 체력 아래에는 현재 페이즈의 패턴 이름을 표시합니다. 전환 후에도 이미 발사된 일반탄·유도탄·
분열탄은 계속 움직이며, 미발사 대기 포격만 정리하고 약 1초간 보스의 다음 사격을 늦춥니다.
이동은 이어집니다. 탄벽은 폭 96px의 빈 통로를 남기며
짧은 점선으로 위치를 표시합니다. 다른 공격까지 안전한 영역이라는 뜻은 아닙니다.

7개 보스 모두 격파 시 연쇄 화재·최종 폭발·잔연기를 거쳐 사라집니다.
6탄 나이트 아크는 선체 화재와 탄약 폭발, 7탄 아이언 리전트는 전용 손상 원화와 중심 동력로 점화를 사용합니다.
화염과 검은 연기만 사용하며, 동력로의 청백색 빛은 작은 중심 점화로 표현합니다. 날아가는 금속 파편은 제거했습니다.
5탄 칼데라 크라운은 원래 포대의 포신까지 교체하는 전용 손상 원화를 사용해, 부서진 무기 아래에 긴 포신이 남지 않습니다.
탄막·불똥이 많아도 격파 연출이 누락되지 않도록 별도로 그리며, 정산으로 넘어가는 시간은 기존 2.4초입니다.

## 적 종류

| 종류 | 표식 | 특징과 예고 |
|---|---|---|
| 소형기 | 없음 | 편대로 몰려온다. 전멸시키면 아이템 |
| 중형기 | 없음 | 멈춰 서서 3방향 확산탄 |
| 저격기 | ◆ 마름모 | 0.5초간 점선 조준선을 보여 준 뒤 **그 각도로 고정해** 2연사한다. 선이 진해질 때 비키면 피한다 |
| 자폭기 | ▲ 삼각형 | 사격하지 않고 들이받는다. 진행 방향에 돌진선과 화살표가 보인다 |
| 폭격기 | ■ 사각형 | 폭탄을 떨어뜨리고, 터질 지점에 점선 원이 먼저 나타난다 |
| 빨강 연사기 | ✚ 십자 | 조준선을 한쪽으로 훑으며 5발을 연달아 쏜다. 훑는 반대쪽으로 빠지면 피한다 |
| 노랑 산탄기 | ◎ 고리 | 사방으로 퍼지는 원형 탄막을 쏜다. 느리게 퍼지므로 탄 사이로 빠져나간다 |
| 초록 추격기 | ⬡ 육각형 | 선회하는 유도탄을 쏜다. 옆으로 크게 돌면 떨궈낼 수 있다 |

색이 다른 세 기체는 표식과 공격 방식이 함께 다르므로 색을 구분하기 어려워도 알아볼 수 있습니다.
빨강은 1스테이지부터, 노랑은 3스테이지부터, 초록은 4스테이지부터 나옵니다.

특수 적은 색조뿐 아니라 꼬리 쪽 도형 표식과 행동 예고선으로 구분됩니다(색만으로 구분하지 않기 위함).

줄이기 전 원본은 `../output/imagegen/striker-src/full-res-2026-10-06/`에 있습니다.

  얹어 구분합니다. 원화가 생기면 `HANDOVER.md` 2장 절차대로 교체하면 됩니다.
- 스테이지 3·5 보스는 `js/boss-art.js` 에서 컨셉 문서대로 캔버스에 그립니다.

## 저사양 기기 고려

- 원본 PNG를 매 프레임 축소하지 않고, 표시 크기에 맞춘 오프스크린 캔버스를 한 번만 만들어
  복사합니다(기체·지상 시설·배경·탄환·프로펠러 모두).
- 렌더 배율은 최대 1.5배로 제한하고, 타이틀에서 `화질 낮음`으로 1배 고정할 수 있습니다.
- 평균 프레임 시간이 길어지면 파티클 수와 프로펠러 표현을 자동으로 줄입니다.
- 적탄 240발, 파티클 220개, 아군탄 140발로 상한을 둡니다.
- 배경은 스테이지에 들어갈 때만 불러오고, 다음 스테이지 배경을 미리 받아 둡니다.

## 접근성

- 모든 버튼에 `type="button"`, 아이콘 버튼에 `aria-label`, 포커스 표시(`:focus-visible`)를 둡니다.
- 상태를 색으로만 알리지 않습니다. 화력·차지·잔기·폭탄은 숫자와 칸을 함께 표시하고,
  보스 약점은 화면에 은은한 빛으로만 표시하되 HUD에 모듈 이름과 내구도를 글자로 보여 줍니다.
- 적탄에 어두운 테두리를 넣어 밝은 배경에서도 구분되게 했습니다.
- `prefers-reduced-motion` 이 켜져 있으면 화면 흔들림을 끕니다.
- 배경 이미지를 못 불러와도 게임은 계속 진행되고, 기체 이미지 로딩에 실패하면 원인과
  `다시 시도` 버튼을 보여 줍니다.
