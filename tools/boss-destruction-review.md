# 보스 격파 그림체와 로딩 검토

## 현재: 5탄 포신 교체와 파편 제거 (v3)

5탄 칼데라에 공용 포대 잔해를 덧씌우던 경로를 전용 손상 원화로 교체했습니다.
좌우 포대 각각의 원래 포신 끝까지 영역을 지운 뒤, 같은 포대의 짧고 부러진 접합부로 바꿉니다.
좌포대만 파괴하면 우포대와 노심은 기존 원화 그대로 남습니다.
날아가는 금속 파편은 전 보스에서 제거했고, 폭발 시트 안의 금속 조각도 화염·연기로 다시 제작했습니다.
파편 이미지 다운로드와 미리보기의 파편 항목도 제거했습니다.

내장 ImageGen 제작 원화·전체 프롬프트는 [`boss-destruction-imagegen-v3.json`](../assets/boss-destruction-imagegen-v3.json),
원본 사본은 `../../output/imagegen/boss-destruction-v3/`에 있습니다.
새 폭발 2장과 칼데라 손상 1장은 WebP 합계 718,706B이며 알파 보존을 검사했습니다.
유지한 리전트 손상 원화까지 포함한 격파 파일은 878,090B입니다.

`node tools/check-boss-destruction.cjs`에서 긴 포신 영역의 원래 알파 픽셀이 사라지는지,
반대 포대·노심 픽셀이 변하지 않는지, 모든 보스의 파편 수가 0이며 파편 원화 요청도 없는지 검사합니다.
전 7탄 격파·일시정지·정산·보상·포화 상태 렌더 검사도 통과했습니다.
현재 캡처와 결과는 `../../output/striker-boss-destruction-qa-v3/`에 있습니다.
게임의 시간 가속·무적을 사용하는 자동 검사이며 시각 선호에 대한 사용자 승인을 뜻하지 않습니다.

## v2 그림체 수정 기록

이전 연출이 게임 원화와 어긋난다는 피드백에 따라 실제 6·7탄 화면을 다시 검토했습니다.

| 확인한 문제 | 적용한 수정 |
|---|---|
| 둥근 입체 불덩이와 큰 청록색 링이 금속 함체 위에 따로 붙인 듯 보임 | 기존 폭발·나이트 아크·리전트 원화를 참고해 위에서 내려다본 화염·검은 연기·금속 잔해 시트를 다시 제작 |
| 작은 연쇄 폭발과 최종 폭발의 질감이 다름 | 작은 점화부터 최종 붕괴까지 새 폭발 원화 사용 |
| 둥근 파괴 부위를 날려 돌덩이처럼 보임 | 찢어진 장갑판·브래킷·트러스·포신의 전용 파편 4종 제작 |
| 선체보다 큰 폭발과 오래 남는 온전한 본체 | 함체 크기에 맞춰 폭발을 줄이고 1.48~2.06초에 본체가 사라지도록 조정 |

내장 ImageGen으로 새 원화 3장을 제작했습니다. 전체 프롬프트·참고 원화·원본 경로는
[`boss-destruction-imagegen-v2.json`](../assets/boss-destruction-imagegen-v2.json)에 있습니다.
고해상도 원본은 `../../output/imagegen/boss-destruction-v2/`에 보관합니다.
이전 v1 원화와 제작 기록도 보존합니다. 리전트 손상 원화는 기존 v1을 계속 사용합니다.

- 함체 화재: `boss-heavy-blast-v2.webp`, 1024² / 16프레임
- 동력로 점화: `boss-reactor-blast-v2.webp`, 1024² / 16프레임, 작은 청백색 점화와 주황 화염
- 금속 파편: `boss-metal-debris-v2.webp`, 512² / 4종

| 이미지 그룹 | 원본 파일 합계 | 게임 로딩 파일 합계 |
|---|---:|---:|
| 이번 폭발 2장·파편 1장 | 4,374,284B | 838,548B |
| 손상 원화까지 포함한 현재 격파 파일 4장 | — | 997,932B |
| 이전 v1 격파 파일 3장 | — | 1,340,604B |

격파용 파일 합계는 이전보다 25.6% 작습니다. 전체 게임·음악 용량이나 실제 로딩 시간의 감소율을 뜻하지 않습니다.
WebP quality90으로 저장하고 인코딩 전후 알파 일치를 검사했습니다.
[`boss-destruction-loading-v2.json`](../assets/boss-destruction-loading-v2.json)에 파일별 수치가 있습니다.
공용 화재·파편은 한 번 받아 재사용하고, 동력로와 리전트 손상 원화는 7탄 배경을 준비할 때만 받습니다.
7탄부터 직접 원화를 불러와도 공용 화재·파편이 함께 준비됩니다.

`node tools/check-boss-destruction.cjs`에서 전 7탄 실제 피해 → 격파 → 정산, 일시정지, 중복 보상 방지,
32프레임 알파, 파편 분할, 파티클 풀 포화, 새 원화 경로·공용 원화 재사용·후반 지연 로딩을 확인했습니다.
6·7탄의 0.4/1.65/1.8/2.2초 장면과 7탄 정상/전체 손상 캡처는 `../../output/striker-boss-destruction-qa-v2/`에 있습니다.
미리보기는 [`boss-destruction.html`](boss-destruction.html)입니다.
시간 가속·무적을 사용하는 브라우저 자동 검사이며, 실제 기기의 모바일 성능이나 사용자 선호를 입증하는 검사는 아닙니다.

## v1 초기 제작 기록

2026-10-06, 현재 7탄 구성과 실제 렌더링 경로를 기준으로 검토했습니다.

| 대상 | 확인한 상태 | 적용한 개선 |
|---|---|---|
| 1~7탄 격파 | 모두 공통 16프레임 폭발이 있었으나 선체 분해와 최종 폭발의 구분이 약함 | 연쇄 폭발 → 원화 파편 비산 → 대형 최종 폭발을 공유하는 2.4초 시퀀스 |
| 6탄 나이트 아크 | 본체·전용 손상 원화가 이미 있음 | 기존 손상 합성을 유지하고 연쇄 화재·선체 파편·탄약 폭발 보강 |
| 7탄 아이언 리전트 | 본체에 공용 잔해를 덧그리던 방식 | 좌우 무장부·동력로 전용 손상 원화와 청백색 동력로 폭발 시트 제작 |
| 파티클이 많은 순간 | 보스 폭발도 일반 파티클 개수 제한에 영향을 받음 | 보스 격파 연출을 별도로 그려 포화 시에도 재생 |
| 지상·야간·공용 잔해 로딩 | 이미 원화로 교체했지만 RGBA PNG가 큼 | 같은 표시 해상도·알파를 유지하는 WebP 사본 사용 |

내장 ImageGen으로 새 원화 3장을 제작했습니다. 전체 프롬프트와 원본 경로는
[`boss-destruction-imagegen-v1.json`](../assets/boss-destruction-imagegen-v1.json)에 있습니다.
고해상도 원본은 `../../output/imagegen/boss-destruction-v1/`에 보관합니다.

- 공용 대형 폭발: `boss-heavy-blast-v1.webp`, 1024² / 16프레임
- 최종 동력로 폭발: `boss-reactor-blast-v1.webp`, 1024² / 16프레임

미리보기는 [`boss-destruction.html`](boss-destruction.html), 결과와 캡처는 `../../output/striker-boss-destruction-qa/`에 저장합니다.

시간 가속·무적을 사용한 자동 검사이며 실제 모바일 프레임률·소리 출력·사람의 시각적 선호는 별도 확인 대상입니다.
