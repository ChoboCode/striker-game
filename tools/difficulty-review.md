# EASY / HARD 난이도 점검

2026-10-06 현재 7탄 구성을 대상으로 점검했습니다. 페이즈별 탄막 다양화를 두 모드에 적용했고,
HARD의 자원·체력·탄속 배율을 기준으로 EASY에 완화 설정을 적용했습니다.
모드별 수치는 [README](../README.md#easy--hard)와 `js/difficulty.js`에 있습니다.

## 수치와 판단

| 탄 | 편대 적 EASY/HARD | 중간보스 HP EASY/HARD | 보스 HP EASY/HARD | 보스 발사 탄 표본 합계 EASY/HARD |
|---|---:|---:|---:|---:|

| 2 사막 | 50 / 75 | 510 / 680 | 2240 / 2800 | 1168 / 2024 |
| 3 빙하 | 93 / 140 | 660 / 880 | 2880 / 3600 | 1270 / 2527 |
| 4 밀림 | 59 / 89 | 810 / 1080 | 3120 / 3900 | 1384 / 2620 |
| 5 화산 | 56 / 84 | 938 / 1250 | 3440 / 4300 | 640 / 1368 |
| 6 야간 | 63 / 95 | 810 / 1080 | 2480 / 3100 | 1439 / 2550 |
| 7 요새 | 100 / 150 | 1013 / 1350 | 3520 / 4400 | 2295 / 4261 |

- EASY는 모든 보스의 모든 페이즈에서 발사 탄 수와 최고 탄속이 HARD보다 낮았습니다.
  위 표의 발사 탄 수 비율은 약 47~58%입니다. 난이도가 같은 비율로 줄었다는 뜻은 아닙니다.
- 3탄은 편대 수가 2탄보다 크게 늘어납니다. HARD 기준 보스 등장까지의 평균 배치 수는
  2탄 1.36기/초 → 3탄 2.69기/초이며 EASY에서도 0.91 → 1.79기/초입니다.
  3탄 진입은 실제 플레이에서 확인할 주요 난이도 전환 구간입니다.
- 최종 7탄은 편대와 보스의 발사량이 모두 높습니다. EASY에서도 최종전의 강도는 유지됩니다.
- 5탄 보스는 발사량이 적어도 고정 방향 포격을 쓰며, 6탄은 선체 HP가 낮아도 촘촘한 탄막을 씁니다.
  탄 수나 HP 하나만으로 각 탄의 체감 순위를 정하지 않았습니다.
- 편대 전멸 아이템은 실제 모드별 편대 수로 추적하고, 짧은 2·3발 패턴과 큰 부채꼴의 좌우 대칭을 유지합니다.

## 검사 방법과 한계

`node tools/test-difficulty.cjs`는 실제 `Bosses.update()`·공격 함수를 사용해 각 보스의 3페이즈를
정상 부위 / 모든 부위 파괴 상태에서 각각 20초씩, 60Hz로 실행합니다. 표의 합계는 보스별 **120초 표본**입니다.
플레이어 목표점은 (240,620), 속도는 모드와 스테이지 배율을 적용합니다. 호위기 발사는 포함하지 않고,
적탄 풀 상한 240발에 걸리기 전의 생성량을 셉니다. 실제 화면의 동시 탄 수와 구분해야 합니다.

`node tools/browser-seven-stages.cjs`는 Edge에서 실제 메뉴·발사·일시정지·복귀를 확인한 뒤,
현재 게임 소스에 검사 훅을 넣고 시간을 가속해 EASY/HARD 각각 1~7탄의 중간보스·보스 3페이즈·부위 파괴·정산·엔딩을 검사합니다.
이 캠페인 검사는 무적을 사용합니다. 별도로 피격·부활·잔기 소진·게임 오버·컨티뉴,
고정 탄속·유도탄 가속 한도, 난이도별 기록·기존 HARD 기록·중복 저장 방지·선택 유지도 확인합니다.
두 모드 전 7탄에서 중간보스를 살려 둔 채 보스 예정 시간을 12초 넘기고, 부분 피해를 주어도
보스 경고·등장이 시작되지 않는지 검사합니다. 실제 `damageEnemy()`로 격파한 뒤에만 경고와 보스가
진행되며, 일찍 격파하면 예정 시간까지 기다리는지도 별도 검사합니다. 대기 중 일시정지와
컨티뉴·새 게임의 예약 상태 초기화도 확인합니다.
390×844 화면과 844×390에서 게임 영역 경계와 메뉴 버튼 접근을 확인했습니다.

결과와 캡처는 `../../output/striker-difficulty-qa/`의 `balance-audit.json`·`results.json` 및 PNG 파일입니다.
실제 사람의 클리어율·회피 여유·조작 피로도, 실제 모바일 프레임률과 소리 출력은 확인하지 않았습니다.
다음 체감 검사는 EASY로 2→3탄 전환과 7탄, HARD로 5→6탄 전환의 난이도 차이를 우선 확인하는 것이 좋습니다.
