# 전투 업데이트

- 일반 공중 편대를 약 1.5배로 증가: 1~5탄 각각 46→69, 50→75, 93→140, 63→95, 100→150기. 보스·중간 보스·별도 증원은 이 합계에서 제외한다. 넓어진 편대는 7기 단위로 줄을 나눈다.
- 랜서는 남색·상아색 쌍발 전용 원화를 사용한다. 좌·정면·우 자세, 회전 프로펠러, 금빛 창 형태 일반탄·보조탄, 금빛 차지샷으로 구분한다.
- 차지샷은 선명한 둥근 입자가 기수로 가속하며 모이고, 응축구가 커진 뒤 고속 관통탄으로 발사된다. 발사 순간 기수에 짧은 충격파가 남으며 탄두 뒤에는 가늘어지는 에너지 꼬리가 붙는다. 스트라이커는 청색, 랜서는 금색이다.
- 클리어 화면의 다음 버튼을 제거했다. 약 3초 후 다음 스테이지로 이동하고, 마지막 스테이지는 엔딩으로 이동한다.
- 보스 부위 내구도가 0이면 폭발 후 파손 이미지가 남는다. 4탄은 기존 전용 파손 원화를 사용한다.
- 1~3탄 보스 본체 체력을 2200·2800·3600으로 높이고 공격 간격과 패턴을 강화했다.

### 랜서 전용 필살기

[랜서 에너지포 미리보기](lancer-burst.html). X 또는 필살기 버튼으로 1회 소모하며, 0.65초 응축 → 1.6초 전방 지속 방출 → 0.35초 잔광으로 이어진다. 황금빛 광선이 기수에서 화면 상단까지 뻗고, 발사 중 기체 이동으로 조준할 수 있다. 일반 사격은 잠시 멈추며 키보드 이동 속도는 절반이 된다. 광선 안의 적탄을 지우고 적·지상 목표·노출된 보스 부위에 지속 피해를 준다. 스트라이커의 기존 폭격은 유지한다.

브라우저 하니스에서 피해, 중복 소모 방지, 일시정지, 종료, 스테이지 초기화, 스트라이커 폭격 유지와 실제 발사 화면을 확인했다. `test-lancer-burst.cjs`에서 20/30/60fps의 지속 피해 시간과 전방 판정을 검증했다.

## 검증 범위

부위 피격·파괴 상태·공격 중단, 적 이동·편대 수에 대한 Node 검사를 통과했다. 브라우저 하니스에서 1탄 클리어 자동 이동, 마지막 탄 엔딩 이동, 차지 발사·일시정지, 랜서 전용 기체와 탄환, 보스 파손 합성을 확인했다. 미리보기에서 파괴 후 잔해 유지와 랜서 차지샷을 시각 확인했다. 이번 수치 변경 후 전체 5개 스테이지의 사람에 의한 난이도 평가는 수행하지 않았다.
